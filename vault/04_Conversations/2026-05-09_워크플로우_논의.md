## 2. Cyril 시스템 vs GNE Monitor 비교

### 핵심 차이: 피드백 루프

#### GNE Monitor (현재)
수집 → AI 요약 → HTML 리포트 → [읽음] → [끝]
- 단방향 정보 전달
- 과거 리포트는 참조 안 됨

#### Cyril 시스템
수집 → Vault 저장 → Claude 분석 → [읽고 메모] → Vault 저장
↑                                                      ↓
└──────────── 다음 분석 시 과거 메모 참조 ────────────┘
- 순환형 지식 축적
- 시간에 걸친 패턴 인식
