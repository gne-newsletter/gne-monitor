# GNE 모니터링 시스템 - 프로젝트 개요

**업데이트**: 2026-05-09

---

## 한 줄 요약

AI 기반 GNE 근병증 최신 정보 자동 수집·분석·뉴스레터 시스템

---

## 핵심 가치

**환자 관점:**
- 최신 논문·임상시험·뉴스를 놓치지 않음
- 전문 용어를 쉽게 풀어서 이해
- 임상시험 참여 기회 발견

**환우회 관점:**
- 금전적 부담 0원
- 인력 투입 0시간
- 회원에게 실질적 가치 제공

**생태계 관점:**
- 정보 민주화
- 환자 역량 강화
- 연구 가속화

---

## 시스템 구조
수집 (매주 자동)
├─ PubMed 논문
├─ ClinicalTrials.gov
└─ Google News (5개 피드)
↓
AI 분석 (Claude API)
├─ 관련도 점수 (1-10점)
├─ 자동 요약
└─ "환자에게 의미" 생성
↓
HTML 리포트 생성
├─ 이번 주 핵심 소식
├─ 데이터 시각화 (Chart.js)
└─ 모바일 반응형
↓
배포 (예정)
├─ GitHub Pages
├─ 이메일 구독
└─ 환우회 전달

---

## 차별화 포인트

| 이 시스템 | 기존 뉴스레터 |
|-----------|---------------|
| 완전 자동화 | 수동 큐레이션 |
| 주간 발송 | 월간/분기 |
| AI 관련도 평가 | 사람 선택 |
| 환자 친화 해석 | 전문 용어 그대로 |
| 무료 오픈소스 | 비공개/유료 |

---

## 기술 스택

**언어**: Python 3.11+
**데이터베이스**: SQLite
**AI**: Claude API (claude-opus-4-7)
**시각화**: Chart.js
**자동화**: schedule (Python)

**비용**: 월 $2~3 (Claude API만)
